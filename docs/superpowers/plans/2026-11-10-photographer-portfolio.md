# Photographer Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the shadcn Next starter into a responsive photographer portfolio with introduction, selected work, pricing, contact, and maintainable placeholder-photo metadata.

**Architecture:** Keep the App Router page as a server-rendered composition of data-driven sections. Store all placeholder photography metadata in a focused typed module, use semantic anchors for navigation, and use global CSS tokens for the editorial color and type system while keeping section layout close to its markup.

**Tech Stack:** Next.js App Router, TypeScript, Tailwind CSS v4, shadcn/ui starter utilities, `next/font/google`, Unsplash remote images.

**Spec:** `docs/superpowers/specs/2026-11-10-photographer-portfolio-design.md`

## Global Constraints

- Start from the generated shadcn Next template committed as the baseline.
- Keep visible copy refined and understated; do not use "premium" or "high-end".
- Use stable Unsplash placeholder URLs and centralize replacement notes in `next-app/app/portfolio-data.ts`.
- Preserve accessible image alt text, focus states, anchor navigation, responsive behavior, and reduced-motion handling.
- Do not add backend forms, a CMS, extra routes, or client state.

```tsx

  <section aria-labelledby="intro-title">eyebrow, H1, biography, hero image, scroll cue</section>
```
